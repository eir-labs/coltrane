## Config decisions

- Provider: `v8` (no Babel transform pass; works directly off the bundle vitest already builds).
- Reporters: `text` (CI summary), `lcov` (codecov / external dashboards), `html` (local browsing
  under `coverage/index.html`).
- `include: ["src/**/*.ts"]` — only first-party code; agents/, evals/, examples/ excluded.
- `exclude: src/test_topology.ts` — recent landing; let it stabilize before counting it against the
  score. Also excluded: `*.d.ts`, `node_modules`, `dist`, `tests`.
- `all: true` — report uncovered files too, not just files touched during the run. Otherwise zero-
  coverage modules silently disappear, and those are the actual finding we're after.
- **No thresholds.** First run is measurement, not enforcement. Threshold gates land in a follow-up
  PR once we know the baseline number.

## How to run

```
npm install --save-dev @vitest/coverage-v8     # one-time
npm test -- --coverage                          # or: npx vitest run --coverage
open coverage/index.html                        # local HTML report
```

`coverage/lcov.info` is the machine-readable artifact for codecov-style integrations.

## Why this matters

492 unit tests + 22 e2e specs all pass. That tells us nothing about what code paths they actually
hit. Coverage answers the question "what are we NOT exercising?" — a file with 0% coverage is a
file with zero proof-of-life, regardless of whether it's imported. Branch coverage in particular
catches the conditional that's never been forced into its else-arm.
