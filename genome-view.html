The six cognitive primitives

Every unit of work is one of six moves. Each primitive produces exactly one output type — the colour follows the type everywhere in this viewer.

SENSE → Signal
INTERPRET → Interpretation
JUDGE → Judgment
PLAN → Plan
CREATE → Artifact
VERIFY → Verdict

Standard

A multi-phase workflow: the score a run performs. It lists phases in order, and each phase seats one or more chairs. The standard is the shape; a run (a "gig") is one performance of it.

Phase

One stage of a standard. A phase carries an intent — what this stage is for — and the chairs that do its work. Phases run in dependency order; a later phase reads the sealed outputs of the ones it depends on.

Chair & seat

A chair is a role in a phase, with a typed input → output contract and skill requirements. A seat is who fills it: an agent, or a human (a review/approval gate). The chair is the job; the agent is the player.

Agent

A named player defined as content, not glue code. It carries cognitive primitives, the types it consumes and produces, a method, constraints, and a tool grant. Agents swap into chairs; a chair is never a bespoke agent.

Type & contract

Data moving between chairs is typed. The input/output contract on a chair names the types it reads and writes, so a phase can only receive what an earlier phase actually produced. Six core types; domain types extend them.

Skill

A reusable cognitive technique bound into an agent by slug. Method travels with the player; the institution supplies the data. A chair can require or merely prefer a skill.

The three identity hashes

content_hash — the bytes themselves. dependency_hash — who it depends on. effective_hash — the binding of the two in a context. Two identical definitions in different contexts get different effective hashes, by design.

Tool grant — deny by default

An agent can only touch what its allowed_tools names. Nothing is implicit; an empty grant is a reasoning-only seat. A grant that resolves to no real provider fails closed rather than pretend.

The sealed ledger

Every run appends to a content-addressed ledger: a genome_hash for the structure that ran, and, per output, a content_sha plus the exact inputs it consumed. Provenance is engine-stamped — the chain records what actually happened.

The institutional layer

Above the workflow sits the institution: who is bound by what, who answers for it, and where the work is allowed to run.

Institution

The governing body: a named sovereign with its own laws, organizations, chairs, and seated agents. It is the boundary of authority — capability crosses to another institution only through a witnessed exchange contract, never implicitly.

Organization

An operating body inside an institution — where the work actually happens. It carries a charter (what it exists to do) and may sit under a parent org. Agents are members of an org; a seating binds a member into a chair for that org.

Law (ADICO)

An institution's rule, written in Crawford & Ostrom's grammar: Attributes (who it binds), Deontic (permitted / obliged / forbidden), aIm (the governed action), Conditions (when), and Or-else (the consequence). Each law also carries a machine check — a predicate over typed inputs — so it can be enforced, not just recited.

Chair vs seat / assignment

A chair is the office: a role, a cognitive function, a mission, its skill floor, its capability grants (caps), and its obligations. It exists whether or not anyone holds it. An assignment (a seat) binds a specific agent into that chair for an org — optionally citing technique evidence for why this player, this office.

Forebear & lineage edge

A forebear is a documented figure a chair's disposition is anchored in — with a domain and exactly what working practice is taken (and nothing more). A lineage edge records the descent from an agent to that forebear, and must cite a real source: an uncited lineage is a recollection, not a record.

Venue

The configured room a workflow runs in — a ceiling, never a grant. Its equipment is the tool ceiling (an agent's effective tools are its own grant ∩ the room's); doors separate ingress from egress; installs are digest-pinned; the credential surface names which credential classes may be present; a lifecycle (ephemeral by default) and one accountable chair answer for it.

Chart & movement

An arrangement: one gig as a performance of several standards. Each movement runs a standard; a typed edge asserts an output sealed by one movement seeds the next; approval gates are human seats between movements; a budget envelope bounds the whole performance, held in a venue.
